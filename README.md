# IJCOMPRA

Sistema moderno de gestión y seguridad. Este proyecto está dividido en un Backend (Node.js + Express + PostgreSQL) y aplicaciones cliente en Flutter (Desktop/Mobile).

## 🚀 Requisitos
- Node.js
- PostgreSQL (Base de datos: `ijcompra_db`)
- Visual Studio / Android Studio (Para compilar Flutter)

## 💻 Backend (API)
Para ejecutar el servidor localmente:

1. Abre tu terminal.
2. Entra a la carpeta del backend:
   ```bash
   cd backend
   ```
3. Ejecuta el servidor en modo desarrollo:
   ```bash
   npm run dev
   ```
El servidor correrá en `http://localhost:3000`.
