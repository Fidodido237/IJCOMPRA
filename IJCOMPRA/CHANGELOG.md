# Changelog

Todos los cambios notables en este proyecto se documentarán en este archivo.

El formato se basa en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto se adhiere al [Versionamiento Semántico](https://semver.org/lang/es/).

## [0.0.1] - 2026-06-04

### Agregado (Added)
- Estructura base del proyecto Node.js.
- Conexión a la base de datos nativa PostgreSQL (`ijcompra_db`).
- Script de inicialización automática de la tabla `usuarios` (`init_db.js`).
- Rutas de la API base para test de estado (`/api/status`), creación y listado de usuarios.
- Configuración de variables de entorno `.env`.
- Archivo `.gitignore` para seguridad de credenciales.
- Documentación inicial (`README.md` y `CHANGELOG.md`).
